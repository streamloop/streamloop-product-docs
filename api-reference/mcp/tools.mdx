The [MCP server](/api-reference/mcp/overview) has **67 tools**. Names are `snake_case`, with no prefix. Each tool's own description (what an agent reads) says when to use it and which tool comes next. This page lists them by area.

- **Scope** is the OAuth scope the tool needs. `write` includes `read`, and `destructive` includes both.
- **Destructive** matches each tool's `destructiveHint` annotation: the tool can't be undone or changes what viewers see. **Yes, confirm** tools are irreversible: they need `confirm: true`, or they answer `Error [CONFIRM_REQUIRED]`, say exactly what would go, and change nothing.
- Every tool publishes an `outputSchema` (the shape it answers), and every error also answers `structuredContent` `{ code, detail, … }`. See [Errors](/api-reference/mcp/overview#errors).

## Scenes

<Info>
  Scenes are in private beta. See [Scenes](/scenes/overview) to request access.
</Info>

The four `scene_*` tools read and change a scene's draft by path. See [Scenes](/api-reference/mcp/overview#scenes) on the overview for the paths, revisions and the publish flow.

| Tool | What it does | Scope | Destructive |
| --- | --- | --- | --- |
| `list_scenes` | The workspace's scenes, newest first, with the version last published. | `read` | |
| `create_scene` | Creates a scene with an empty draft. | `write` | |
| `rename_scene` | Renames a scene. | `write` | |
| `scene_get` | Reads anything in the draft by path, or a published version. `as: "image"` returns a picture of a frame or layer with any problems found. | `read` | |
| `scene_set` | Creates or changes one thing in the draft: a whole value or exact text edits. Checked as the studio checks it. Changing what exists needs the `revision` you read (`"*"` on purpose), or it answers `REVISION_REQUIRED`. | `write` | |
| `scene_remove` | Deletes whole things from the draft, all or nothing. Each path needs the revision you read (`"*"` on purpose). | `write` | Yes |
| `scene_probe` | Fetches a URL once to show what a table would read from it. Changes nothing. | `read` | |
| `publish_scene` | Publishes the draft as it was at `draftRevision` (required) as the next version. `dryRun` only checks; on air it needs `confirm: true`; `STALE_PUBLISH` when someone published since your draft's base. | `write` | Yes |
| `list_scene_versions` | Published versions, newest first: number, when, by whom. | `read` | |
| `revert_scene` | Publishes an earlier version again as the next version. Needs `expectedVersion` (the latest published version you saw); on air it needs `confirm: true`. | `write` | Yes |
| `discard_scene_draft` | Puts the draft back to the published version. Every change since is lost. Needs the `draftRevision` you reviewed; `dryRun` lists what would be lost first. | `destructive` | Yes |
| `delete_scene` | Deletes a scene and all its versions. Refused while a stream plays it. Without `confirm` it names the scene, its versions and the streams that play it. | `destructive` | Yes, confirm |
| `set_stream_scene` | Makes a stopped stream play a scene's published version, or go back to its playlist. | `write` | |
| `get_scene_state` | What each stream playing the scene has on air: the frame (`frame`), the next one (`next`), controls and sources. | `read` | |
| `control_scene` | Acts on air: takes a frame to air with a transition (`goFrame`), cues the next (`next`), sets a control, replaces a table's rows, skips a track. | `write` | Yes |
| `list_scene_inputs` | The scene's ingest keys (never the key itself), secret names and IP cameras. | `read` | |
| `create_scene_ingest_key` | Gets the RTMP, RTMPS and SRT addresses and key for an encoder such as OBS. The key is shown once. | `write` | |
| `revoke_scene_ingest_key` | Revokes an ingest key. The encoder using it is cut off at once. | `destructive` | Yes, confirm |
| `set_scene_secret` | Saves an API key that a table sends. It's sealed and never shown again. | `write` | |
| `delete_scene_secret` | Deletes a secret. Tables that use it stop getting it. | `destructive` | Yes, confirm |
