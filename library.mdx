The **Library** holds every video and audio file uploaded to your workspace. Open it from **Library**
in the dashboard's top navigation.

## Find a file

- **Search files** by name.
- Filter by **File type** (**All**, **Video** or **Audio**) and by **Usage**: **In use** shows
  files in a loop's playlist, and **Unused** shows the rest.
- Select a file to **Preview** it.

## Upload files

Click **Upload files**, or drop video or audio files anywhere on the page. You can also upload from
a loop's playlist. Everything lands in the same library.

To use a library file in a loop, open the loop's **Playlist** tab and click **From library**.
Nothing is uploaded twice.

## Rename a file

Select a file and use **Rename file**. This only changes the name shown in Streamloop. Loops
using the file keep playing it.

## Remove files

<Steps>
  <Step title="Select the files">
    Select one file, or several at once.
  </Step>
  <Step title="Remove them">
    Click **Remove** and confirm.
  </Step>
</Steps>

<Warning>
  Removing is permanent. The files are deleted from storage and can't be recovered.
</Warning>

You can't remove a file that's used in a loop. Take it out of the loop's playlist first, then remove
it.

<Note>
  Uploads that aren't in any playlist are removed automatically after 14 days.
</Note>
